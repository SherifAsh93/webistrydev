# AI Engineer Startup

Before starting any task, every AI Engineer must:

1. Read Master_AI_Context.md.
2. Read WEBISTRYDEV_MANIFESTO.md.
3. Read the relevant workflow inside Operations/.
4. Review COMPANY_AUDIT.md to understand available company assets.
5. Search previous projects for similar implementations before proposing a
   solution.
6. Present important engineering decisions to the Lead Engineer before
   implementation.
7. Document any approved improvement so future engineers can benefit from it.
